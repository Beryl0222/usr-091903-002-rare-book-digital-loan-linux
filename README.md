# 古籍数字借展管控

服务用于协调英、法、日、德等馆藏机构中华古籍的数字母版、展示许可与发布窗口，
确保每次公开使用都能核对来源，且授权不会因跨国时区提前开始或逾期。

运行 `python3 service.py --check` 可核对服务配置；执行 `python3 service.py --port 8000`
后访问 `/health` 确认服务身份，领域接口位于 `/v1/` 下。

## 领域模型

- **机构 / 古籍**：古籍归属于唯一馆藏方，带书目版本信息。
- **母版 MasterScan**：交付时核验 SHA-256，不符即拒收；可设 `sealed_until`（开幕前封闭）。
  馆方替换扫描件时旧母版指向新母版，已发布版本撤回但快照保留、可复原。
- **衍生图 Derivative**：`highres` / `preview` / `thumbnail` 三级，均关联母版并各自带校验值；
  其中 `highres` 属于受限高清内容。
- **页面**：页序分版本；每页携带缺损说明与色彩校准信息。出版社修正页序产生新版本。
- **许可 License**：分 `image`（图像）与 `text`（文字解说）两类，各自约定
  地域集合、当地起止日期与署名要求，登记时按馆藏方时区换算为 UTC 半开区间 `[start, end)`。
- **批准 Approval**：每份许可须经批准；发布快照记录具体批准编号。
- **发布 Release**：不可变快照，固化母版校验值、页序版本、衍生图清单、批准编号与署名。

## 关键规则

1. **交付校验**：文件与 SHA-256 不符直接拒收，不进入登记。
2. **时间语义**：只接受显式带时区偏移的时刻；授权按当地日期换算 UTC，
   起始前一刻不生效、截止时刻整即失效（东京 10 月 1 日的授权对应 `09-30T15:00Z` 至 `10-01T15:00Z`）。
3. **发布前三重核对**：当前地域与时刻下图像许可有效、文字解说许可有效、两份许可均已批准且均有署名要求；
   封闭期内高清衍生图不得发布（预览图可发布）。
4. **变更与失效**：替换母版、缩短授权、临时下架、修正页序均撤回现行发布并令缓存与下载令牌失效；
   缩短但仍合规的发布保持在线，但旧链接作废、需重新签发，新窗口截止后自然关闭。
5. **可复原**：任一展示过的版本可按当前许可复核后以原快照复原（母版、页序版本、批准编号不变）；
   许可已失效或母版仍封闭时拒绝复原。
6. **来源可溯**：`GET /v1/releases/{id}/provenance` 说明页面使用了哪份母版（含校验值）与哪次批准。
7. **分馆可见**：机构审计接口只返回本机构资料的访问与使用记录。
8. **高清内容隔离**：未经许可或封闭中的 `highres` 内容不出现在接口响应、审计日志或导出包中；
   图像字节仅用于校验，下载接口只返回标识与校验值。

## 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/v1/institutions` | 登记馆藏机构 |
| POST | `/v1/works` | 登记古籍与书目版本 |
| POST | `/v1/works/{id}/masters` | 交付母版（`data_b64`、`sha256`、可选 `sealed_until`） |
| POST | `/v1/masters/{id}/derivatives` | 交付衍生图 |
| POST | `/v1/works/{id}/pages` | 建立页序、缺损说明、色彩校准 |
| POST | `/v1/works/{id}/page-order` | 修正页序（新版本） |
| POST | `/v1/works/{id}/licenses` | 授予图像/文字许可（含地域、当地日期、时区、署名） |
| POST | `/v1/licenses/{id}/approve` | 批准许可 |
| POST | `/v1/licenses/{id}/shorten` | 缩短授权 |
| POST | `/v1/works/{id}/publish` | 核对并发布 |
| POST | `/v1/works/{id}/rollback` | 复原历史发布版本 |
| POST | `/v1/releases/{id}/takedown` | 临时下架 |
| POST | `/v1/releases/{id}/downloads` | 按当前许可签发下载令牌 |
| GET | `/v1/downloads/{token}?at=&region=` | 解析令牌（逐次复核许可与封闭状态） |
| GET | `/v1/releases/{id}/provenance` | 母版与批准来源说明 |
| GET | `/v1/institutions/{id}/audit` | 本机构访问与使用记录 |
| GET | `/v1/works/{id}/export?at=&region=` | 导出包（自动剔除未授权高清内容） |

## 测试

- `npm test` 同时运行服务契约测试与 17 项领域规则测试。
- 领域代码位于 `loan/`：`timeutil`（时区窗口）、`intake`（交付登记）、
  `licensing`（许可批准）、`publishing`（发布/下架/复原/下载）、`audit`（审计与导出）、`api`（HTTP 门面）。
